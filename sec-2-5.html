    Section 2.5 Linear Inequalities in Two Variables

    In this lesson we graph the solutions to linear inequalities in two variables, and to systems of linear inequalities. We also find the vertices of the solution set. These skills are used when solving two-dimensional optimization problems subject to a set of constraints.
    Begin by asking the class: How is an inequality in two variables different from an equation? How are the solutions different? How are their graphs different? (Remember that a graph is just a picture of all the solutions.)

    Activity 2.5.1. Graphing a Linear Inequality.

    Graph the solutions to the linear inequality
    \begin{equation*} 3x - y \le -2 \end{equation*}
    The first step is to graph the equation \(3x - y = -2\text{.}\) This line will be the boundary line for the solution set.

    2. Use the slope-intercept method to graph the line.

    3. Next, use a test point to locate the solutions of the inequality. (We can use any point for a test point, as long as it does not lie on the line!) We’ll use \((1,4)\text{.}\) Label this point on your graph. Use algebra to decide whether \((1,4)\) is a solution of the inequality \(3x - y \le -2\text{.}\)
    4. Which side of the line includes all the solutions of the inequality? Shade that side of the line. Is the line itself included in the solution set?
    5. Can you suggest an easier test point instead of \((1,4)\text{?}\)
    6. Graph the solutions to each inequality. (How do you know whether to make your boundary line solid or dashed?)
      1. \(~~y - 3x \lt 6\)
      2. \(~~y \gt \dfrac{-3}{2} x\)

    Activity 2.5.2. Systems of Inequalities.

    To graph the solution set of a system, graph each inequality separately, one at a time. Shade each solution region lightly (or use different colors) so that you can see their intersection.
    It’s important for students to complete the graph of each inequality in the system separately, before going on to the next one. Have students number the inequalities and label each boundary line with its number.
    1. Graph each inequality in the system:

    Subsection 2.5.1 Check Your Understanding

    1. In Activity 1, what are the intercepts of the boundary line?
    2. In Activity 2, why is the graph of \(y=2\) a horizontal line?
    3. In Activity 3, what is the easiest method to use to find the intersection of Line 1 and Line 2?
    4. What portion of the Cartesian plane is described by the inequalities \(x \gt 0\) and \(y \gt 0\text{?}\)

    Subsection 2.5.2 Wrap-Up

    In this Lesson, we worked on the following skills and goals related to linear inequalities:
    • Graph the solution set for an inequality in two variables
    • Graph the solution set for a system of inequalities
    • Find the vertices of the solution set

    Subsection 2.5.3 Questions for Writing or Discussion

    1. What is the difference between the graphs of an equation in two variables and an inequality in two variables?
    2. When is it wrong to use \((0,0)\) as a test point? What should you do instead?
    3. Why do we shade the intersection of the solution sets when solving a system of inequalities?
    4. What does the word "vertex" mean for a system of inequalities?

    Concept Questions.

    1. The solutions of \(x \gt -4\) all lie to which side of the boundary line?
      1. Above
      2. Below
      3. To the left
      4. To the right
    2. Which point would not be a good test point for the inequality \(y \le \dfrac{2x}{3}\) ?
      1. \(\displaystyle (0,0)\)
      2. \(\displaystyle (1,1)\)
      3. \((2,3)\text{.}\)
      4. \(\displaystyle (-1,-1)\)
    3. To find the vertices of the solution set for a system of inequalities, we
      1. use a test point.
      2. use a system of inequalities.
      3. solve a system of equations.
      4. find the \(x\)-intercepts.
    4. The first quadrant includes all the solutions of
      1. \(x+y \gt 0\text{.}\)
      2. \(x-y \gt 0\text{.}\)
      3. \(xy \gt 0\text{.}\)
      4. \(x \gt 0\text{,}\) \(~y \gt 0\text{.}\)
